# dentro

**Tu clínica, por dentro.** CRM SaaS para clínicas y consultorios dentales en México: leads, pacientes, citas, doctores, presupuestos, pagos, documentos y seguimientos en una sola app, enfocado en el dueño y la administración interna.

Producto de la Fábrica de productos digitales (Diego Castro + Lalo Castro).
